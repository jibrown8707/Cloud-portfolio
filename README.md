## Core Projects

### Active Directory User & Access Management

Simulated an enterprise Active Directory environment by deploying a Windows Server on AWS and configuring it as a Domain Controller.

- Created and managed user accounts
- Designed Organizational Unit (OU) structure by department (IT, HR)
- Implemented group-based access control (RBAC)
- Applied domain password policies and account configuration
- Validated system behavior and troubleshot domain configuration warnings

https://github.com/jibrown8707/active-directory-user-access-management

---

### IT Support Ticketing System

Simulated a technical support environment by designing and managing support tickets to reflect real-world issue handling workflows.

- Created and categorized support tickets based on issue type and severity
- Documented troubleshooting steps and resolution paths
- Practiced prioritization and structured problem-solving
- Simulated production-style support workflows and issue tracking

https://github.com/jibrown8707/it-support-ticketing-system

---

### AWS Networking Infrastructure (Terraform)

Provisioned AWS infrastructure using Terraform to simulate a production-style networking environment.

- Built custom VPC with public and private subnets
- Configured Internet Gateway and NAT Gateway
- Implemented route tables and subnet associations
- Applied security groups and launched EC2 instances
- Designed segmented network architecture for controlled access

https://github.com/jibrown8707/aws-networking-terraform

---

### Serverless REST API

Built a serverless backend using AWS Lambda and API Gateway.

- Configured API Gateway to handle HTTP requests
- Integrated Lambda for backend processing
- Implemented IAM roles and permissions
- Enabled CloudWatch logging for monitoring and troubleshooting

https://github.com/jibrown8707/serverless-rest-api-aws

---

### Static Website on AWS

Designed and deployed a secure static website using AWS services.

- Hosted website on Amazon S3
- Distributed content using CloudFront
- Configured custom domain with Route 53
- Enabled HTTPS using AWS Certificate Manager

https://github.com/jibrown8707/static-website-aws

---

### Amplify React Deployment

Deployed a React application using AWS Amplify with CI/CD.

- Connected GitHub repository to Amplify
- Configured automatic builds and deployments
- Delivered a publicly accessible HTTPS application

https://github.com/jibrown8707/amplify-react-deployment

### AI Support Knowledge Assistant (RAG)

Built a Retrieval-Augmented Generation (RAG) application using Amazon Bedrock.

- Integrated S3 and OpenSearch Serverless for document retrieval
- Used Amazon Bedrock for response generation
